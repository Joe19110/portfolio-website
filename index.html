About

Hi, I'm Joelliane

I'm a third-year Computer Science and Software Engineering student who likes building things that are meant to be used, not just graded.

I've realized that the part of tech I enjoy most is figuring things out. I like taking an idea that doesn't fully make sense yet, breaking it down, and working through the problems until I understand how to make it work. A lot of that ends up being debugging, experimenting, and probably going down a few unnecessary rabbit holes along the way.

I also care a lot about the people using what I build. I don't want to think of software as just something that works technically. I like thinking about how someone would actually use it, where they might get confused, what happens when something goes wrong, and whether the solution makes sense from their perspective.

That's also why I like working on things outside what I already know. I've worked across mobile development, AI, web development, and research, and each one has forced me to approach problems differently. I usually learn the most when I don't already know the answer.

Right now, I'm still figuring out exactly where I want to take that curiosity, but I know I want to keep building, keep learning, and work on problems where I get to understand both the technology and the people using it.

    Highlighted project

    BINUS EDM DESA

    Backend Data Engineering AI Engineering

    My deepest, most current work at the intersection of all three focus areas.

    Role: Associate Member Data Engineer, BINUS IT Division

    Type: Internal tool, in active development.

    An internal platform centralizing the data engineering team's workflow: pipeline failures, data quality issues, access requests, schema changes, source onboarding; replacing ad-hoc ticket handling with one system. It includes an AI chatbot with tool access to live pipeline infrastructure.

    Stack

    • Built a data sanitization step and, downstream of it, an error classifier for automated error detection within Delman pipelines.
    • Linked the error-classification pipeline to Langfuse for tracing and observability.
    • Implemented the RAGAS evaluation pipeline for the project's RAG system.
    • Implemented RustFS (S3-compatible object storage) integration for pipeline archive storage.
    • Used Docker for containerized execution and n8n for workflow automation.
    • Currently building complex chatbot features including command/skill-based actions, not just Q&A.
